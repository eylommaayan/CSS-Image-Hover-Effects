## 📖 על הפרויקט

מיקרו-אינטראקציות על גבי תמונות מהוות נדבך קריטי בעיצוב ממשקי משתמש מודרניים (גלריות, אתרי מסחר, פורטפוליו ועמודי נחיתה).  
פרויקט זה נבנה ככלי לימודי ומציג דף אינטראקטיבי יחיד שבו ניתן לבחור מתוך 24 אפקטים שונים, לצפות באנימציה החיה, לקרוא את ההסבר בעברית, ולראות במדויק את פקודת ה-CSS המפעילה כל אפקט.

## 🎯 פירוט 24 האפקטים והפקודות המרכזיות

| # | שם האפקט | פקודת CSS מרכזית | תיאור קצר |
|---|---|---|---|
| **1** | זום וסיבוב עם כותרת שקופה | `transform: scale(1.3) rotate(15deg);` | התמונה גדלה ומסתובבת קלות בעוד שכבת הטקסט נחשפת |
| **2** | כותרת נכנסת מלמעלה ותמונה הפוכה | `transform: translateY(-100%) -> (0);` | הכיתוב מחליק מלמעלה והתמונה מסתובבת בכיוון נגדי |
| **3** | החלפת מקומות אנכית (Push Down) | `img: translateY(100%);` | התמונה נדחפת מטה והשכבה השחורה תופסת את מקומה |
| **4** | פס תחתון (30%) מתרומם | `height: 30%; transform: translateY(100%);` | פס כיתוב קומפקטי עולה מתחתית הכרטיס |
| **5** | שכבה צבעונית מסתובבת ב-45° | `rotate(45deg) scale(2.2);` | רקע צבעוני מלוכסן שמסתובב ומכסה את כל השטח |
| **6** | מסגרת לבנה וזום פנימי | `border: 10px solid white; scale(1.2);` | זום פנימי של התמונה בתוך מסגרת עבה ויציבה |
| **7** | כניסה מדורגת של טקסטים בדיליי | `transition-delay: 0.3s, 0.4s, 0.5s;` | הכותרת, הפסקה והכפתור נכנסים מכיוונים נגדיים בהפרשי זמן |
| **8** | שילוב סיבובים וכניסות אלכסוניות | `translateY(300px) rotate(90deg);` | כניסה סיבובית של פסקת הטקסט יחד עם יישור שכבה אלכסונית |
| **9** | כיווץ התמונה ל-0 (Shrink & Reveal) | `img: scale(0); bg: scale(1) rotate(0);` | התמונה מתכווצת לנקודה ושכבה מסתובבת נחשפת במקומה |
| **10** | זום ענק ממרחק (Zoom-In) | `transform: scale(10) -> scale(1);` | טקסטים ענקיים מתכווצים מגודל עצום אל תוך הפוקוס |
| **11** | סיבוב כפול 720° והיעלמות | `transform: rotate(720deg) scale(0);` | סיבוב מהיר של 2 סיבובים שלמים עד להיעלמות התמונה |
| **12** | צמצם מעגלי מתרחב (Iris Reveal) | `clip-path: circle(0% -> 75%);` | חשיפת שכבה עליונה מתוך עיגול שמתרחב מהמרכז |
| **13** | זכוכית מטושטשת (Frosted Glass) | `backdrop-filter: blur(8px);` | טשטוש התמונה ברקע ומראה זכוכית חלבית יוקרתי |
| **14** | וילונות אלכסוניים (Diagonal Slices) | `clip-path: polygon(...);` | חיתוך גיאומטרי זוויתי של שכבת הכיסוי |
| **15** | כרטיס תלת-ממדי מרחף (Pop & Glow) | `translateY(-12px); box-shadow:...;` | התרוממות הכרטיס כולו יחד עם צל רך וזוהר |
| **16** | זום קולנועי איטי (Ken Burns) | `transition: transform 5s ease-out;` | תנועת מצלמה איטית ועמוקה כמו בסרטי טבע ויוקרה |
| **17** | מסך מפוצל שנפתח (Curtain Split) | `::before / ::after: translateX(±100%);` | שני חצאי וילון כהים נחצים לצדדים וחושפים את התמונה |
| **18** | משחור-לבן לצבע מלא | `filter: grayscale(100%) -> (0%);` | מעבר מתמונה מונוכרומטית מנוגדת לצבעים עשירים |
| **19** | קרן אור אלכסונית (Light Sweep) | `transform: skewX(-25deg); left: 160%;` | קרן אור חולפת במהירות ומדמה הברקת זכוכית |
| **20** | חלון זרקור עגול (Spotlight Mask) | `filter: brightness(0.25) -> (1);` | תמונה חשוכה המתבהרת בחדות רק במעבר עכבר |
| **21** | היפוך מראה אופקי (Mirror Flip) | `transform: scaleX(-1);` | היפוך התמונה ביחס ימין-שמאל ב-180 מעלות |
| **22** | גליץ' צבעים דיגיטלי (RGB Glitch) | `drop-shadow(4px red) drop-shadow(-4px cyan);` | פיצול ערוצי צבע ורעד של מסך סייברפאנק |
| **23** | מסגרת פנימית מתרחבת (Outline Inset) | `::before: border; scale(0) -> scale(1);` | מסגרת לבנה מופיעה ומתרחבת ממרכז התמונה |
| **24** | ספיה לצבע מוגבר (Retro to Vibrant) | `filter: sepia(80%) -> saturate(140%);` | מעבר מגוון עתיק לצבעוניות מודרנית רוויה |
